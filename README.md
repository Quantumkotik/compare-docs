# Загрузка двух документов .docx

Веб-приложение: FastAPI на бэкенде, HTML + CSS + JS на фронтенде.
Позволяет загрузить два файла `.docx` и посмотреть их содержимое и статистику.

## Установка

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

## Запуск

```bash
.venv\Scripts\python main.py
```

Скрипт поднимает сервер на `http://127.0.0.1:8080` (если порт занят — берётся
свободный) и открывает интерфейс в браузере.

Порт и хост можно задать переменными окружения `PORT` и `HOST`.

## Структура

- `main.py` — точка входа: запуск сервера и открытие браузера
- `app/server.py` — FastAPI: маршруты `/`, `/api/upload`, `/api/health`
- `app/docx_reader.py` — разбор `.docx` (текст, заголовки, таблицы, статистика)
- `static/` — интерфейс: `index.html`, `styles.css`, `app.js`

## API

`POST /api/upload` — multipart-форма с полями `first` и `second` (оба `.docx`).
Возвращает JSON со списком `documents`: имя файла, размер, автор, даты,
количество слов/символов/абзацев/таблиц/изображений, заголовки и текст.
Ограничение — 25 МБ на файл. Документация: `/api/docs`.
