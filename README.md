# Сравнение двух документов .docx

Веб-приложение: FastAPI на бэкенде, HTML + CSS + JS на фронтенде.
Загружает две версии документа `.docx` и показывает различия между ними.

## Установка

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

## Запуск

```bash
.venv\Scripts\python main.py
```

Скрипт поднимает сервер на `http://127.0.0.1:8080` (если порт занят — берётся
свободный) и открывает интерфейс в браузере. Порт и хост можно задать
переменными окружения `PORT` и `HOST`.

## Как это выглядит

- **слева** — старая версия: красным подсвечено то, чего больше нет в новой;
- **справа** — новая версия: зелёным подсвечено добавленное и изменённое;
- строки выровнены попарно, напротив удалённого или добавленного абзаца
  на второй стороне остаётся пустая полоса в штриховку;
- внутри изменённого абзаца подсвечиваются конкретные слова, а не абзац целиком;
- сверху — сводка и две диаграммы: состав абзацев (без изменений / изменено /
  удалено / добавлено) и сравнение версий по словам, символам, абзацам и таблицам.

Сравнивается весь текст в порядке документа — абзацы и строки таблиц.

## Запуск в Docker (Ubuntu-сервер)

Нужны `docker` и плагин `docker compose` (Ubuntu 22.04/24.04):

```bash
sudo apt update && sudo apt install -y docker.io docker-compose-v2
sudo systemctl enable --now docker
```

Сборка и запуск:

```bash
docker compose up -d --build
```

Приложение поднимется на порту 8080: `http://<адрес-сервера>:8080`.
Другой внешний порт задаётся переменной `PORT`:

```bash
PORT=9000 docker compose up -d --build
```

Полезное:

```bash
docker compose logs -f
docker compose ps
docker compose down
```

Контейнер перезапускается сам (`restart: unless-stopped`) и имеет healthcheck
по `/api/health` — состояние видно в `docker compose ps`.

Внутри образа сервер запускается напрямую через `uvicorn` на `0.0.0.0:8080`;
`main.py` не используется, потому что он открывает браузер и сам выбирает порт.
Калькулятор в образ не входит — это оконная программа, серверу она не нужна.

За `nginx` с TLS добавьте в `Dockerfile` к команде запуска
`--proxy-headers --forwarded-allow-ips "<ip прокси>"` и не публикуйте порт
контейнера наружу.

## Структура

- `main.py` — точка входа: запуск сервера и открытие браузера
- `app/server.py` — FastAPI: маршруты `/`, `/api/upload`, `/api/health`
- `app/docx_reader.py` — разбор `.docx` (текст, заголовки, таблицы, статистика)
- `app/diff.py` — выравнивание абзацев и различия по словам (`difflib`)
- `static/` — интерфейс: `index.html`, `styles.css`, `app.js`
- `Dockerfile`, `docker-compose.yml` — запуск на сервере

## API

`POST /api/upload` — multipart-форма с полями `first` (старая версия) и
`second` (новая версия), оба `.docx`. Возвращает JSON:

- `documents` — по каждому файлу: имя, размер, автор, даты, количество
  слов/символов/абзацев/таблиц/изображений, заголовки и текст по строкам;
- `diff.rows` — выровненные пары `left`/`right`; у каждой стороны `kind`
  (`equal`, `changed`, `removed`, `added`) и `parts` — куски текста
  с пометкой `changed`;
- `diff.stats` — счётчики строк и слов и доля совпадения `similarity`.

Ограничение — 25 МБ на файл. Документация: `/api/docs`.

# Калькулятор

Отдельная мини-программа: окно на tkinter (входит в стандартную поставку Python,
ставить ничего не нужно).

## Запуск

```bash
.venv\Scripts\python -m калькулятор
```

В PyCharm: открыть `калькулятор/__main__.py` и нажать «Run» (`Shift+F10`).

## Возможности

- операции `+ − × ÷ % **` и скобки, приоритет операций учитывается;
- ввод с клавиатуры (цифры, операции, `Enter` — посчитать, `Backspace` —
  стереть, `Esc` — сброс) и мышью по кнопкам;
- после `=` цифра начинает новый пример, а операция продолжает вычисление
  с полученным результатом;
- запятая работает как точка;
- понятные сообщения об ошибках: деление на ноль, некорректное выражение,
  слишком большая степень.

Выражение разбирается через `ast` и вычисляется по белому списку операций —
`eval` не используется, произвольный код выполнить нельзя.

## Файлы

- `калькулятор/__main__.py` — окно и обработка ввода
- `калькулятор/вычислитель.py` — разбор и вычисление выражения
